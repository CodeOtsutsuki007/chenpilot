# Documentation Archive

Completed implementation and delivery reports that no longer describe active
guidance. They are kept as issue evidence, with their Git history preserved
(`git log --follow <archived path>`). See the
[documentation archival policy](../DOCUMENTATION_ARCHIVAL_POLICY.md) for when a
report is moved here.

Every file in this directory must have a row in the manifest below.
`npm run docs:check` verifies the manifest, checks that no maintained document
still points at an original path, and checks that each archived report is
linked from [INDEX.md](../../INDEX.md).
